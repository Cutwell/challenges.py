# Pac-man Gym

## Getting started

* Install with `uv sync`
* Run with `uv run python src/main.py`

## About

In reinforcement learning (RL), "gyms" are simulated environments wherein our RL agent can "learn" the environment and maximise the reward signal through thousands of repeated attempts.

In this challenge, we use our `pacman` game logic as the basis for our gym environment.
